# Web 管理台使用说明（含远程访问）

## 一、怎么在浏览器打开网页

项目启动后（`python web/app.py`，默认端口 8080），在**任意一台能访问服务器的电脑**的浏览器地址栏输入：

```
http://222.242.152.65:8080
```

如果你的电脑和服务器在同一内网，也可以填服务器的内网 IP，例如 `http://192.168.1.100:8080`。

打不开时按顺序检查：

1. **服务是否在运行**：在服务器上执行 `python web/app.py`，看到 `Web 管理台启动: http://...` 即成功；
2. **防火墙是否放行 8080**：
   - Windows：`netsh advfirewall firewall add rule name="ReportWeb" dir=in action=allow protocol=TCP localport=8080`
   - Linux：`sudo ufw allow 8080/tcp`（或 iptables）
3. **是否用了云服务器安全组**：阿里云/腾讯云控制台 → 安全组 → 入方向放行 TCP 8080；
4. **浏览器访问的是公网 IP**：确认服务器有公网 IP 且 8080 未被运营商封禁（80/443 更稳妥，配合 nginx 反代）。

> 首次打开如果提示输入令牌，填 `deploy/start_web.ps1` 或环境变量里设置的 `REPORT_WEB_TOKEN` 值。

## 二、页面功能

| 页面 | 功能 |
|---|---|
| 总览 | 六桥卡片：配置是否正常、最近报告、待补图/缺失值数量，一键生成 |
| 生成报告 | 选桥 → 周期（**季度 / 年度** / 月 / 周 / 手动）→ 结束日期 → 开始生成，轮询进度 |
| 下载报告 | 列出该桥 outputs 下的 .docx，一键下载 |
| 数据覆盖 | 每个指标有传感器数、有数据数、最早/最晚日期 |
| 待补清单 | 上次运行未匹配到的图表占位符与未解析单元格 |
| 配置管理 | **填入数据存放路径**（统计值/图库/传感器对照/名称字典，可测试路径）、**上传报告模板**、报告命名前缀 |
| 调度器 | 查看/修改调度周期（季度/年度/月/周 + 日期时间），一键启动/停止常驻调度器 |
| 日志 | agent / scheduler / web 日志尾部 |

## 三、常见配置示例（Web 配置管理页填写）

- 统计值目录：`D:/bridge/统计值`（服务器实际路径）
- 图库目录：`D:/bridge/图库`
- 传感器对照表：`D:/bridge/传感器对照/传感器编号名称.json`（固定产物）
- 名称对照字典：`D:/bridge/传感器对照/传感器名称对照/赤石大桥.json`（固定产物）

保存后点“测试路径”可验证；模板上传支持 .docx，上传后自动写入配置。
