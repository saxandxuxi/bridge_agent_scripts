============================================================
桥数据预处理 - 项目使用说明
============================================================

一、三个文件夹的用途
------------------------------------------------------------
1. 处理脚本\   存放所有处理数据的脚本(预处理、图库、对照表生成等)
2. 图库\       存放各传感器各特征的统计图
   - <传感器编号>\<特征>\时间序列图.png   每日均值/最大/最小曲线
   - <传感器编号>\<特征>\频率分布图.png   小时均值分布直方图
   - <传感器编号>\相关性_<特征A>_<特征B>.png  特征间相关性散点图(可选)
3. 统计值\     存放查询用的统计值 JSON(全部中文键)
   - 传感器编号名称.json   编号 -> 中文监测部位对照(由 docx 生成)
   - <传感器编号>.json     每个传感器的分特征统计(不写每日统计明细)
   - 位置统计\<位置>.json  位置统计库：{位置:{测点X:{特征:{统计,传感器编号}}}}
   - 总览.json             全部传感器的总览

二、处理流程
------------------------------------------------------------
第 1 步: 原始数据预处理(按天聚合为小时统计)
    python 处理脚本\preprocess_sensor_data.py --mode preprocess \
        --data-root D:\信科采集软件解析数据 --output-root D:\preprocess_sensor_data \
        --bridge 赤石 --start 2026-01-01 --end 2026-03-31 --resume
    输出(绝对路径): D:\preprocess_sensor_data\<桥名>\daily_2026.1~3\<传感器>\<特征>\<日期>.csv
    说明: summary.csv 会在结束后自动按 传感器/特征/日期 排序去重;
           断点续跑跳过的任务也会回填汇总记录，不再丢失。
           断点续跑(--resume)默认开启，已生成的日级文件自动跳过；
           确需全部重跑时加 --no-resume。
           摸底表(inventory.csv)按桥写入 <output-root>\<桥名>\inventory.csv；
           再次运行时若该桥已有摸底表会自动复用、跳过耗时摸底扫描；
           需要重新摸底时加 --mode inventory 强制扫描。

第 2 步: 生成图库 + 统计值
    python 处理脚本\build_chart_library.py --mode merged --year 2026 \
        --quarter 1 --bridge 赤石 --features "DZJSD(xJsd)" --skip-per-sensor
    默认读取(绝对路径): D:\preprocess_sensor_data\<桥名>\daily_2026.1~3
    输出(相对路径): preprocess\图库_2026.1~3\<桥名>\ 和 preprocess\统计值_2026.1~3\<桥名>\
    --bridge 不填时自动按传感器对照表里的桥名推导；预处理和建图库必须用同一个桥名。

    常用参数:
      --correlation     同时生成特征间相关性分析图(默认关闭)
      --limit-sensors N 只处理前 N 个传感器(试跑)
      --start/--end     只统计指定日期范围
      --daily-root/--lib-root/--charts-dir/--stats-dir  覆盖输入输出路径
      --vibration-date YYYY-MM-DD  振动(秒级)指定出图日期(默认自动取数据最完整的一天)
      --rebuild-summary 先从 daily 目录重新生成 summary.csv，再生成图库
                        (不重跑预处理，适合 daily 已有、汇总表丢失/不全时)

    第 2.5 步: 生成季度/年度统计值(快速：读统计库，按特征汇总全桥)
    季度:
    python 处理脚本\build_quarterly_stats.py --period quarterly --mode stats
        --lib-root D:\Code\data_analysis\preprocess --bridge 赤石
        --start 2026-01-01 --end 2026-03-31
    输出: 统计值_<期>\<桥名>\季度总结\季度统计.json
          (结构: 桥 -> 特征 -> {全桥统计, 位置:{位置:{测点X:{统计, 传感器编号}}}})
    年度(daily-root 传桥根目录，汇总其下所有 daily_* 子目录):
    python 处理脚本\build_quarterly_stats.py --period yearly --mode stats
        --lib-root   D:\Code\data_analysis\preprocess --bridge 赤石
        --start 2026-01-01 --end 2026-12-31
    输出: 统计值_<期>\<桥名>\季度总结\年度统计.json
    说明: 默认 --mode stats 直接读 统计值_<期>\<桥名>\位置统计\ 下的
    统计库(位置 -> 测点 -> 特征)，以特征为最高键汇总全桥，不重读 daily；
    --mode daily 保留按小时级原始数据重算。pipeline.py(web 预处理管道)
    已把该步骤串入(图库生成之后自动执行)。报告代理读取时优先
    位置统计\<位置>.json 的测点特征；逐传感器文件读不到时回退到
    季度总结\季度统计.json 按 特征->位置->测点 查找(数据血缘)。

    统计前统一清洗(与绘图同一套逻辑):
      - 物理合理范围过滤: 湿度 0~100%、温度 -80~80℃、风速 0~100 m/s、
        索力 0~10 万 KN、位移/挠度 ±10 万 mm、应变 ±5 万 με 等，
        超出范围的值(如采集错误码 435000、9e7)一律用稳健基线替代并记录；
        边界带量程百万分之一的容差，避免基线贴近边界(如索力≈0)时把
        微小测量噪声(-1e-06)误判为超范围导致满图红点；
        仅当 >=98% 数据落在物理区间内该范围才生效(硬过滤)；
        否则认为范围与传感器量程/单位不符，仅作绘图参考、不硬过滤，
        交由分布极端点/尖峰逻辑处理，并在记录中写明"命中率xx%"
      - 零散尖峰替代 + 规律性高峰保护(见上文)
      - 同一监测部位同一特征有多个传感器时，按小时取各传感器均值，
        最大值取各传感器最大、最小值取最小

    图库生成失败/数据不足时会记录到: 图库\生成失败记录.txt

    合并图(merged)版面：≤3 个测点/特征时子图纵向堆叠、每个子图占满宽度；
    4~6 个时用两列子图网格；超过 6 个自动拆成多张图(时间序列图.png /
    频率分布图.png 及 _2.png、_3.png ...)，每张不超过 6 个子图，避免子图
    过小、标注看不清。报告侧会自动把拆出的后续图片在同一图表位置后一并
    插入(约 5.8 英寸宽、上限 6.5 英寸高，不与正文重叠)。单传感器的
    轴/方向分量组(如 GNSS Δx/Δy/Δz、EZJD xJd/yJd、DZJSD xJsd)按
    三行一列竖排，每幅子图占满整幅宽度，两侧留白最小化。
    振动(DZJSD 等秒级特征)：per_sensor 与 merged 都只出一张时间序列图
    (时间序列图.png)——每天只加载当天数据(约 8.6 万点)，在期内挑选
    数据最完整的一天(可用 --vibration-date YYYY-MM-DD 指定)；
    横轴为 0~24 小时(刻度 0/6/12/18/24 时)，标题含具体年月日；
    频率分布图仍按季度逐日累积。报告侧若存在旧版按天文件
    (时间序列图_YYYY-MM-DD.png)会自动取日期最新的一张。

    进一步预处理(默认开启，生成统计值和图之前执行):
      - 数据按小时级加载(daily 每天 24 行)，时间序列图一天描 24 个点，
        横轴仍标日期；只有没有 daily 时才回退 summary.csv(日级)
      - 零散尖峰点(均值/最大/最小三个序列各自检测): 滑动(重合)窗口法——
        每个窗口去掉 1 个最小+1 个最大后看局部分布，被去掉的极值偏离
        窗口中心超过 --spike-threshold 倍窗口尺度、且被 >=2 个重合窗口
        命中才算尖峰候选；连续超过 3 个点的长段属于持续偏高/偏低，
        不判尖峰(走标注)；每个序列最多替代 --max-spikes(默认3)个
        最极端的，其余视为正常分布尾部不替代；
        风向类(spfx/szfx 圆形量)不做尖峰判定只做范围过滤；风速
        (spfs/szfs)允许剔除零散尖峰(真实大风/阵风长段不会被误删)；
        分布极端点(--dist-k)：单个孤立点偏离超过 dist_k×尺度(默认20)视为
        异常值，按偏离程度排名最多剔除 --max-removals(默认5)个；
        连续超过 3 个点的异常段不剔除，改为在时间序列图上着色并标注
        紧凑时间段(如 "1.18 3~1.19 5 偏低"，同年省年份)；dist-k=0 时
        关闭散点异常值剔除(异常段标注仍用默认带宽)。分布极端点与零散
        尖峰合计最多剔除 5 个，按偏离程度排名，物理范围外/非有限值不计入；
        替代记录写入 JSON 的 "预处理.尖峰替代"，图上 黑x=统计尖峰、
        红x=物理范围外/分布极端点剔除；同一小时在多天重复出现的
        "规律性高峰"(如早晚高峰)视为常态不替代；时间序列图只绘制
        均值序列，图上的 X 只标注均值序列的剔除点(最大值/最小值序列
        的清洗记录仍保留在 JSON 的 "预处理.尖峰替代" 中)
      - 数据缺失(连续 >= --gap-fill-hours 小时，默认24): 在图上橙色
        标注缺失区间("数据缺失 Nh: x月x日x时~x月x日x时 (已线性填充)")，
        绘图序列用首尾有效值线性插值填充；统计值仍按真实数据计算，
        缺失区间写入 JSON 的 "预处理.数据缺失填充"
      - 长时间突变段: 当天"偏高/偏低小时"占比 >= 60%、且连续
        >= --shift-min-days 天(默认 7)才判定为突变区间；在时间序列图上
        着色并标注 "x月x日x时~x月x日x时 均值xx 偏高/偏低"(精确到小时)，
        区间详情写入 JSON 的 "预处理.突变区间"
      - 标注不封顶: 缺失/突变段全部着色并逐条标注(紧凑格式)，不再只标
        最长的前几条；≤4 段时文字统一放图上方留白区逐行排列(y 轴自动
        预留行高，不压数据线段、不重叠)，>4 段时文字统一挪到子图右侧
        留白区逐行排列，图上只保留色带。
      参数: --spike-threshold 5.0(默认) / --gap-fill-hours 24(0=关闭) /
            --max-spikes 3 / --max-removals 5 / --dist-k 20(0=关闭) /
            --shift-threshold 2.5 / --shift-min-days 7；
            流量/计数类特征(如人流量)建议 --spike-threshold 0 关闭尖峰替代

    第 3 步(一次性): 生成传感器编号对照表(完善版)
    python 处理脚本\parse_sensor_map.py [docx路径] [输出json路径]
    说明: 解析《五座桥测点编号表格.docx》时，会把"位置"列的方位
    (上游/下游/左幅/右幅/左/右/顶/底 等)拼进传感器名称与监测部位，
    如 "随州侧边跨跨中箱梁内顶板上游"；同一监测部位不同方位会拆成
    不同位置(文件夹)，避免某个位置子图过多。X/Y/Z 等方向分量仍作为
    同一传感器的特征编码(如 GNSS(Δx/Δy/Δz))，不拆位置。
    已生成:
      - 传感器对照\传感器编号名称.json(1157 个传感器, 含特征编码)
      - 传感器对照\传感器名称对照\<桥名>.json(每桥一个, 完善版):
          * 传感器名称 -> [{编号, 特征, 位置, 方向, 特征编码, 测点}]
          * 测点映射: 结构应变/振动监测表 断面位置 -> 测点N -> 编号
          * 表格映射: 梁端支座位移/墩顶支座倾角/裂缝/温湿度/结构温度 表
    传感器对照表是固定产物(不随季度变化)，统一放 preprocess\传感器对照\；
    特征编码来自 Q1 统计值(自动读取 统计值\ 目录)，
    先跑完预处理和图库统计再执行本脚本，映射最准确。


三、统计值 JSON 里的中文键
------------------------------------------------------------
平均值 / 中位数 / 标准差 / 最大值 / 最小值 / 差值 /
最大值_实测 / 最小值_实测 / 绝对最大值 / 均方根值 /
有效小时数 / 缺失小时数 / 覆盖天数(不写每日统计明细)

四、参考脚本说明
------------------------------------------------------------

(时间序列图、频率直方图、相关性密度散点图+回归线,
